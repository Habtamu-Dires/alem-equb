# Alem Digital Equb

 Alem Digital Equb is a web-based FinTech application that modernizes the traditional Ethiopian Equb—a community-based rotating savings system. Traditionally, Equb members contribute a fixed amount regularly, and a randomly selected member wins the pooled money each cycle. My platform digitizes this process, eliminating manual tasks and enhancing transparency. This project showcases my expertise in secure financial applications, real-time transaction handling, and automation—helping to digitize a widely used traditional financial practice.


 ## Technologies used 
  Spring Boot, Spring Data Jpa, PostgreSQL, Angular , TailWind CSS.
